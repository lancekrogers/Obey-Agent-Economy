## Description

```
Autonomous AI agents that trade, predict, infer, and coordinate across 6 blockchains — all within human-set spending boundaries enforced at the smart contract level. Every decision is verifiable on-chain.

OBEY Agent Economy is a multi-agent system where an ERC-4626 vault enforces spending limits (max swap size, daily volume, token whitelist, slippage) at the EVM level. The agent literally cannot exceed them. 8 pre-trade risk gates evaluate every opportunity before execution, and the agent's ERC-8004 identity builds portable, verifiable reputation from its track record.
```
